# CodeIgniter 4 Exercises Repository

This repository contains several small projects in the form of **CodeIgniter 4 exercises**, with each exercise located in its respective folder.

These exercises are **not full-featured CodeIgniter 4 projects**. They are designed primarily for **educational and learning purposes**.

Please read the `README.md` file inside the respective exercise folder carefully and follow the provided instructions to execute the exercise successfully.

## Requirements

Before executing any of the exercises, make sure the following requirements are installed and properly configured:

* **Windows OS** — Latest version, preferably Windows 11 or higher
* **XAMPP** — Latest version
* **PHP** — Version 8.0 or higher

  * Make sure the required PHP extensions are enabled in `php.ini`, including:

    * `intl`
    * `curl`
    * `zip`
    * `mbstring`
* **Composer** — Latest version
* **Git** — Latest version
* **Active Internet Connection** — Preferably a broadband connection

## Getting Started

After fulfilling all the requirements above:

1. Clone or download this repository.
2. Navigate to the folder containing the exercise you want to run.
3. Open the `README.md` file inside that exercise's folder.
4. Follow the instructions provided in that `README.md` file.
5. Make sure all required dependencies and configurations for the specific exercise are completed.
6. Execute the exercise according to its instructions.

> **Note:** Each exercise may have its own setup requirements and execution steps. Always refer to the `README.md` file within the respective exercise folder before running it.

## Purpose

The exercises in this repository are intended for **learning and educational purposes only**. They demonstrate various concepts and techniques related to **CodeIgniter 4** and should not necessarily be considered production-ready applications.

## Important

Please ensure that your development environment meets all the requirements listed above before attempting to execute any exercise.

For exercise-specific instructions, always refer to the `README.md` file located inside the corresponding exercise folder.
