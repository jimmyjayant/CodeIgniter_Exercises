This is a CodeIgniter version 4 Exercises repository.
It contains several little projects in the form of exercises in their respective folders.
The exercises are not full featured CodeIgniter version 4 projects. 
The exercises are meant for educational purposes only.
Please read the instructions in the respective folder's readme.md files to execute successfully.

Requirements before executing the respective exercises:- 
Windows OS Latest version (Preferably 11 or higher)
XAMPP (Latest version)
PHP 8.0+ (With several extensions such as intl, curl, zip, mbstring enabled in php.ini file.)
Composer (Latest version)
Git (Latest version)
Active Internet Connection (Preferably Broadband)

After fulfilling these requirements, please follow the instructions in the respective folder readme.md file to execute the exercise or project successfully.
